  • ✓ 브랜드별 11종 프리셋: Sony DCR, Canon IXY, Cyber-shot, Instax Mini, Polaroid, Hi8 Tape, Super 8mm, Kodak Gold, Fuji Superia, Tri-X Noir

  • ✓ Web Audio API 기반 기계식 셔터 찰칵 햅틱 사운드 & Dynamic Island 상태 연동
