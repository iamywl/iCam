## 2. 과거 실패에 대한 기술적 처방 (Zero-Compromise Engineering Rules)

한도윤은 이전 개발 코드에서 발생한 모든 색채 참사를 다시는 허용하지 않는다:

1. **CSS `hue-rotate()` 전면 폐기**:
   - 색상환 전체를 통째로 돌려 피부색을 녹색/보라색으로 망가뜨리는 원시적 CSS 트릭을 금지한다.
   - 특정 색상(예: 나뭇잎 Green → Emerald)만 옮기려면 **색상각 가우시안 마스크 기반의 선택적 3D LUT / HSL 벡터 회전**만 사용한다.
2. **하이라이트 오렌지 오염 폐기 → 진짜 Point-Source Halation 파이프라인**:
   - 이전처럼 픽셀 단독 루프에서 `if (luma > 0.82) r += ...` 하는 방식은 흰 옷과 밝은 피부까지 누렇게 오염시킨다.
   - 할레이션은 반드시 **(1) 극고휘도 점광원 Threshold Extract → (2) 분리형 가우시안 블러 확산(Multi-pass Blur) → (3) Red/Orange 가중 Screen/Additive 합성**의 3단 광학 패스로만 구현한다.
3. **고정 정적 노이즈 폐기 → Bell-Curve Density-Dependent Grain**:
   - 화면 전체를 회색 먼지로 덮는 `mix-blend-mode: overlay` SVG 노이즈 레이어를 금지한다.
   - 진짜 필름 입자는 미드톤($L \in [0.25, 0.70]$)에서 가장 잘 보이고 순백·순흑에서는 사라지는 **밀도 의존형 종형 곡선(Bell Curve)**을 따라야 하며, 프레임 간 자연스러운 랜덤 시드를 가진다.
4. **블랙 미스트는 Mask Bloom으로만**:
   - 전체 이미지 블러가 아니라 하이라이트 마스크 블러 후 은은한 확산 블렌딩으로만 구현한다.
5. **프리뷰 = 캡처 100% 일관성 (Single Source of Truth)**:
   - 뷰파인더에서 보던 색감과 실제 찍혀 나온 사진의 톤·그레인·비네팅이 **단 1%의 배신도 없이 동일 파이프라인**을 공유해야 한다.
   - CPU 메인 스레드 픽셀 루프(`getImageData` 전수 스캔)로 셔터 랙·뷰파인더 끊김을 만들지 않고, GPU 셰이더 기반 실시간 파이프라인을 지향한다.
