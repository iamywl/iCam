# 사진작가 & 감성 페르소나 도시에 (Persona Collective Index)

> **"좋은 카메라 앱은 엔지니어가 만든 필터 목록이 아니라, 서로 다른 눈을 가진 사진작가들의 암실이 한 손 안에 들어온 것이다."**

이 폴더는 단순한 역할극용 메모가 아니라, 향후 카메라 앱의 모든 **색채 과학(Color Science), 뷰파인더 경험, UI 절제, 셔터 감각**을 심사하고 거부권(VETO)을 행사할 수 있는 **11인의 크리에이티브 페르소나 정의서**입니다.

## 협업 및 검수 프로토콜 (How the Council Works)

새로운 카메라 감성이나 UI를 기획·검증할 때는 반드시 아래 순서를 따릅니다:

1. **빛과 피사체 정의 (`00 강서진`)**: 이 장면에서 무엇이 주인공인가? 기본 카메라 대비 빛과 인물이 어떻게 더 아름다워지는가?
2. **감성 DNA 고정 (`01~08 해당 작가`)**: 각 감성 작가가 자신의 톤 커브·피부 규칙·광학 결함·금지 클리셰를 제시한다.
3. **물리 광학 검증 (`09 한도윤`)**: 프리뷰와 실제 저장 이미지가 1:1로 일치하는지, 픽셀 단위의 왜곡·색 뭉개짐이 없는지 검증한다.
4. **현장 3초 블라인드 테스트 (`10 윤하늘`)**:
   - *"이걸로 찍은 게 기본 카메라보다 확실히 예쁘고 감성적인가?"*
   - *"뷰파인더와 버튼에 촌스러운 광택이나 시각 공해가 없는가?"*
   - 단 하나라도 "글쎄..."가 나오면 즉시 **REJECT** 후 재조율한다.
