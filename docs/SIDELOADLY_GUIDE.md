# 📱 iPhone 15 Pro Max - Sideloadly 네이티브 앱 설치 가이드
> **문서 버전**: v1.0.0  
> **대상 기기**: iPhone 15 Pro Max, iPhone 16 Pro, iPad (iOS 17.0 이상)  
> **개발 PC 환경**: Windows 10 / 11 (Mac 컴퓨터 불필요!)  

---

## 📌 개요 (Overview)
본 문서는 **Mac 컴퓨터가 없는 Windows PC 환경**에서도, GitHub 클라우드의 무료 Mac 서버를 통해 빌드된 **`iCam.ipa`** 파일을 다운로드받아 보유하신 **iPhone 15 Pro Max에 실제 네이티브 앱으로 1분 만에 설치하고 테스트하는 전체 과정**을 설명합니다.

사파리 웹 브라우저(PWA) 접속이 아닌, **아이폰 홈 화면에 정식 앱으로 설치되어 실제 48MP 카메라 센서와 Metal 가속 엔진을 직접 구동**합니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│                   Windows ➔ iPhone 15 Pro Max 설치 흐름                 │
├────────────────────────────────────────────────────────────────────────┤
│ 1. GitHub Actions (무료 Mac 클라우드) ➔ iCam.ipa 자동 빌드 생성        │
│ 2. Windows PC에서 GitHub 접속 ➔ iCam.ipa 파일 다운로드                 │
│ 3. Windows용 무료 프로그램 [Sideloadly] 실행                          │
│ 4. iPhone 15 Pro Max를 USB-C 케이블로 Windows PC에 연결                │
│ 5. Sideloadly에 iCam.ipa 드래그 & 본인 Apple ID 입력 후 [Start] 클릭   │
│ 6. 아이폰 홈 화면에 [iCam] 정식 네이티브 앱 설치 완료! 🎉               │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 🛠️ 사전 준비물 (Prerequisites)
1. **Windows PC** (인터넷 연결)
2. **iPhone 15 Pro Max** 및 **고속 USB-C 케이블**
3. **개인 무료 Apple ID** (평소 앱스토어 로그인에 사용하는 계정, 유료 개발자 결제 불필요!)
4. **Windows용 iTunes 드라이버** (Sideloadly가 아이폰을 인식하기 위한 표준 드라이버)

---

## 🚀 1단계: GitHub Actions에서 `iCam.ipa` 다운로드받기

1. 웹 브라우저에서 iCam GitHub 저장소 접속:
   👉 **`https://github.com/iamywl/iCam`**
2. 상단 메뉴 탭에서 **[Actions]**를 클릭합니다.
3. 좌측 워크플로우 목록에서 **`📱 Build iOS IPA (Sideloadly & TestFlight)`**를 선택합니다.
   - *팁: 원할 때 언제든지 우측 상단의 `[Run workflow]` 버튼을 눌러 새 빌드를 직접 즉시 생성할 수 있습니다.*
4. 가장 최근에 완료된(초록색 체크 표시 `✔`) 빌드 실행 항목을 클릭합니다.
5. 페이지 맨 아래로 스크롤하면 **Artifacts (산출물)** 섹션이 보입니다.
6. **`iCam-iOS-Sideloadly-IPA`**를 클릭하여 다운로드합니다.
7. 다운로드된 `iCam-iOS-Sideloadly-IPA.zip` 파일의 압축을 풀면 **`iCam.ipa`** 파일이 준비됩니다.

---

## 💻 2단계: 윈도우 PC에 Sideloadly 설치하기

**Sideloadly**는 탈옥 없이 개인 Apple ID를 이용해 iOS 기기에 앱을 직접 사이드로딩 설치해 주는 전 세계에서 가장 검증된 무료 유틸리티입니다.

1. Sideloadly 공식 웹사이트에 접속합니다:  
   👉 **[https://sideloadly.io](https://sideloadly.io)**
2. **`Download Sideloadly for Windows 64-bit`**를 클릭하여 다운로드 후 설치합니다.
3. *(참고)* Sideloadly 설치 중 iTunes 및 iCloud 드라이버 설치 안내가 나오면 **안내에 따라 'Web Version(비-스토어 버전)' 드라이버를 설치**해 줍니다.

---

## 🔌 3단계: iPhone 15 Pro Max를 PC에 USB-C로 연결하기

1. iPhone 15 Pro Max를 USB-C 케이블로 Windows PC에 연결합니다.
2. 아이폰 화면에 **"이 컴퓨터를 신뢰하겠습니까?"** 팝업이 뜨면:
   - **[신뢰]**를 터치하고 기기 암호를 입력합니다.
3. Windows PC에서 `Sideloadly` 프로그램을 실행합니다.
4. Sideloadly 상단의 **`Connected Device`** 드롭다운에 **본인의 `iPhone 15 Pro Max` 이름이 정상적으로 표시되는지 확인**합니다.

---

## 📲 4단계: Sideloadly로 1클릭 앱 설치하기

```
┌────────────────────────────────────────────────────────┐
│  Sideloadly 창 구성                                    │
├────────────────────────────────────────────────────────┤
│  Device: [ iPhone 15 Pro Max (iOS 17.x)           ▼ ]  │
│                                                        │
│  ┌────────────────┐                                    │
│  │   [ IPA 아이콘 ] │ ◀── 여기에 iCam.ipa 드래그 & 드롭!   │
│  └────────────────┘                                    │
│                                                        │
│  Apple ID: [ your-email@icloud.com                  ]  │
│                                                        │
│  [ Start ] ◀── 클릭!                                   │
└────────────────────────────────────────────────────────┘
```

1. **IPA 파일 등록**:
   - 1단계에서 압축 해제한 **`iCam.ipa`** 파일을 마우스로 끌어서 Sideloadly 좌측 상단의 **커다란 IPA 박스** 안에 드래그 앤 드롭합니다.
2. **Apple ID 입력**:
   - `Apple ID` 칸에 본인의 Apple 계정 이메일을 입력합니다.
3. **설치 시작**:
   - 하단의 **`[Start]`** 버튼을 클릭합니다.
4. **인증 진행**:
   - 계정 암호를 묻는 창이 뜨면 Apple ID 비밀번호를 입력합니다.
   - 아이폰 화면에 뜨는 6자리 2단계 이중 인증 코드를 PC 화면에 입력합니다.
   - *(개인 서명 용도로만 애플 공식 서버와 통신하며, 비밀번호는 로컬에 안전하게 저장됩니다.)*
5. **설치 완료**:
   - 하단 진행 로그에 `Installing...` ➔ `Done.`이 표시되면, **iPhone 15 Pro Max 홈 화면에 `iCam` 앱 아이콘이 생성**됩니다!

## 🔑 5단계: 아이폰에서 최초 1회 승인 설정 (필수!)

보안을 위해 애플 정책상 처음 설치한 개인 앱은 1회 승인이 필요합니다.

### 1) 기기 관리 신뢰 승인
1. 아이폰 15 프로 맥스에서 **[설정] > [일반] > [VPN 및 기기 관리]**로 들어갑니다.
2. **[개발자 앱 (Developer App)]** 아래에 본인의 Apple ID 이메일이 표시되어 있습니다.
3. 본인 계정을 탭한 후 **[“your-email@...” 신뢰]**를 누르고, 팝업에서 **[신뢰]**를 터치합니다.

### 2) 개발자 모드 켜기 (iOS 16, 17, 18 공통)
1. 아이폰 **[설정] > [개인정보 보호 및 보안]**으로 들어갑니다.
2. 맨 아래로 스크롤하여 **[개발자 모드 (Developer Mode)]**를 탭합니다.
3. 스위치를 **[켬 (On)]**으로 변경하면 기기 재부팅 안내가 뜹니다.
4. **[재시동]**을 눌러 아이폰이 재부팅된 후, 잠금 해제 시 뜨는 팝업에서 **[켜기]**를 누르면 모든 설정이 끝납니다!

## ❓ 자주 묻는 질문 & 트러블슈팅 (FAQ)

### Q1. 무료 Apple ID로 설치한 앱은 7일마다 다시 설치해야 하나요?
- 애플 정책상 무료 계정으로 직접 사이드로딩한 앱의 인증서는 7일 동안 유효합니다.
- 7일이 지나 앱이 안 열릴 때는, 아이폰을 PC에 꽂고 Sideloadly에서 **[Start]만 다시 한 번 누르면** 기존 촬영 사진과 설정이 그대로 유지되면서 7일이 다시 연장됩니다.
- *(Sideloadly 설정에서 'Automatic Refresh via Wi-Fi'를 켜두면 같은 Wi-Fi에 있을 때 PC가 알아서 무선 자동 갱신해 줍니다!)*

### Q2. Sideloadly에서 아이폰이 인식되지 않아요.
- PC에 Apple 공식 iTunes 드라이버가 없는 경우입니다. Microsoft Store 버전 대신 **Apple 공식 웹사이트 버전의 iTunes(64-bit)**를 설치하시면 즉시 인식됩니다.
- 케이블 연결 시 아이폰 화면에서 반드시 **[이 컴퓨터를 신뢰]**를 눌러주셔야 합니다.

### Q3. 유료 개발자 계정($99/년)이 있으면 어떻게 되나요?
- 유료 계정이 있으시다면 유효기간이 365일(1년)로 늘어나며, Apple 공식 **TestFlight**에 올려 케이블 없이 무선으로 모든 팀원에게 배포할 수 있습니다.
